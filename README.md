# Enhancing-Audio-Visual-Cross-Modal-Alignment-with-Contrastive-Dual-Encoders
This project introduces a contrastive learning framework to bridge audio and image modalities using a dual-encoder architecture. By leveraging pretrained backbones—OpenL3 for audio and ResNet50 or CLIP for images—we align spectrograms and visual scenes in a shared 128-dimensional embedding space.
